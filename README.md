# avilacarlosdev-social

Imágenes de los carruseles de las redes de [avilacarlosdev.com](https://avilacarlosdev.com) (Instagram, Facebook y LinkedIn).

`python3 generar.py [carrusel]` arma cada diapositiva en HTML con la paleta del sitio y la captura con Chromium a 1080×1350. Las imágenes quedan en `out/`.
